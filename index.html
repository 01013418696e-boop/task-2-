المقدمه

شهدت شبكة الإنترنت تطوراً هائلاً منذ نشأتها، فبعد أن كانت صفحات الويب عبارة عن نصوص جامدة، ظهرت الحاجة إلى فصل محتوى الصفحة عن طريقة عرضها. ومن هنا ظهرت لغة CSS عام 1996 لتنسيق صفحات الويب وتحويل الشفرات البرمجية إلى واجهات مستخدم جذابة

ما هي لغة CSS؟

هي لغة تنسيق وليست لغة برمجة بالمعنى التقليدي، فهي لا تحتوي على شروط معقدة أو عمليات حسابية، بل تستخدم لوصف كيفية عرض العناصر المكتوبة بلغات الترميز مثل HTML و XML.

ماذا تفعل هذه اللغة بالصفحة؟

  • تحديد الألوان والخلفيات.
  • التحكم في الخطوط والأحجام.
  • تخطيط الصفحة.
  • تنظيم المسافات والهوامش.
  • التصميم المتجاوب.
  • إضافة الحركات والتأثيرات.

لماذا تعد لغة CSS مهمة؟

فصل التصميم عن المحتوى: تساعد على فصل شكل الصفحة عن المعلومات الموجودة بها.

سرعة التحميل: تساعد على توحيد التصميم وتنظيم صفحات الموقع.

القواعد الأساسية لكتابة كود CSS

يتكون كود CSS من ثلاثة عناصر أساسية:

  • المحدد (Selector): تحديد العنصر المراد تنسيقه.
  • الخاصية (Property): تحديد نوع التنسيق.
  • القيمة (Value): تحديد قيمة التنسيق.

أنواع التنسيق

التنسيق الخارجي: كتابة أكواد CSS في ملف منفصل ثم ربطه بصفحة HTML.

التنسيق الداخلي: كتابة أكواد CSS داخل وسم Style في صفحة HTML.

التنسيق المباشر: كتابة التنسيق مباشرة داخل عنصر HTML.

أدوات ومكتبات مساعدة

مع زيادة تعقيد المشاريع ظهرت أدوات تساعد المطورين على كتابة أكواد CSS بشكل أسرع وأكثر كفاءة.

Bootstrap

يعد من أشهر أطر العمل، ويحتوي على تنسيقات جاهزة للأزرار والجداول والنوافذ المنبثقة.

Tailwind CSS

نظام حديث يعتمد على فئات CSS لتوفير مرونة كبيرة في تصميم صفحات الويب.

مرونة التصميم وتوزيع العناصر

تعتمد جاذبية الموقع على الألوان والخطوط وكذلك ترتيب وتنظيم المحتوى والفراغات المتوازنة.
